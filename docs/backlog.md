## 第三档：让人愿意回来打开（对应最早担心的留存问题）

（已完成 2026-11-23）方案和实现记录见决策 0014，五项一次做完；借用 geo-sleuth 查表数据也在 0014 里。线上服务端已重新部署（2026-11-24，连同决策 0016 的改动）；还没上手机测。

| 问题                                        | 解决方法                                                                               |
| ------------------------------------------- | -------------------------------------------------------------------------------------- |
| 记录多了找不到                              | 时间线顶部加搜索框和筛选（类别、标签、地点）；数据都在本地，直接在内存里过滤即可       |
| 没有"第一次 / 重逢"和统计                   | 用地名加距离判断"第几次来"，卡片上显示；首页加一行统计：多少条记录、几个城市、几次出行 |
| 没有回顾                                    | 先做"一次出行的总结"（几天、几个地方、一张长图），再做"一年前的今天"，最后是月度和年度 |
| 分享图只有一种版式，最多 4 张，正文会被截断 | 加 2–3 种版式（单张大图、九宫格、长图）；正文过长时自动换成长图版式                    |
| 地图没有收集感                              | 去过的城市在地图上点亮，标记上显示去过几次                                             |
