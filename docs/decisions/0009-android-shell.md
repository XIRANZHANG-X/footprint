# 0009 安卓外壳：网页打包进 App，AI 调线上接口

- 状态：已定（2026-11-07）

## 背景

决策 0004 定了"网页 + 安卓（Capacitor）"。P1 实测网页版在安卓上就能读到照片的 GPS，
做安卓外壳的理由从"读位置"变成：数据不受浏览器清理影响、没网也能打开和浏览、桌面上有一个真正的 App。
公网接口已经部署在 Cloudflare Workers 上（决策 0007、0008）。

## 决定

用 Capacitor 把构建好的网页（`dist/`）打包进安装包，需要 AI 时访问线上接口。

- 前端的接口地址可配置：`VITE_API_BASE`。网页版为空（同源 `/api`），App 版写在 `.env.app` 里，
  指向 workers.dev 地址。接口地址不是密钥，可以提交。
- 服务端只允许 App 自己的来源（安卓 `https://localhost`、iOS `capacitor://localhost`）跨域访问；
  访问口令照常校验，跨域放行不等于免口令。
- WebView 里不能用 `<a download>` 保存文件，也没有网页的系统分享，
  所以 App 里"保存图片""导出备份"改为：写到 App 的缓存目录 → 打开系统分享面板（可以存到文件、发微信）。
  网页版行为不变。
- 分享图在 App 里只有一个"存相册并分享…"按钮：先存进系统相册的"足迹手账"相簿，再打开分享面板（2026-11-08 用户定，见下面的实测）。
  存相册用自己写的小插件 `GallerySaverPlugin.java`，走安卓 10 起的媒体库接口，不需要存储权限；
  安卓 9 及以下不支持，只提示原因，照样打开分享面板。备份 zip 仍然只走分享面板。
- App 和网页版的数据是分开的两份，迁移用"备份 → 导入"。

## 备选方案

| 方案                         | 不选的原因                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------- |
| 外壳直接加载线上网址         | 没网就打不开，旅行途中最常遇到；Capacitor 官方说明这种用法只适合开发调试；本质上是书签         |
| 不做外壳，改用"添加到主屏幕" | 数据仍归浏览器管理；以后用相册、系统分享等原生能力受限。作为不装 Android Studio 的轻量替代保留 |

## 已知风险（需要真机验证）

- 安卓 10 起，App 读取照片里的位置需要"访问媒体位置"权限，系统选择器返回的照片可能被抹掉 GPS。
  网页版在 Chrome 里能读到，App 里要重新实测；读不到时再加权限申请。
- 录音需要麦克风权限，已在清单里声明，首次录音时系统会弹窗。
- 网页更新后，App 要重新打包安装才能拿到新版。
- 打包需要开发者本机安装 Android Studio（含 Android SDK 和 JDK）。

## 实测（2026-11-08，用户的安卓手机）

口令、照片位置（不需要额外申请"访问媒体位置"权限）、录音、AI 整理、备份导出导入、飞行模式打开都正常。
唯一的问题：分享面板里没有"保存到相册"，图片只能分享出去、存不下来。

处理时考虑过的做法：

| 做法                                  | 不选的原因                                    |
| ------------------------------------- | --------------------------------------------- |
| 社区插件 `@capacitor-community/media` | 多一个第三方依赖，是否支持 Capacitor 8 要实测 |
| 用 Filesystem 写到"文档"文件夹        | 相册里看不到；安卓 11 起写公共目录有限制      |
| 保存和分享做成两个按钮                | 用户要的是一步完成：点分享就顺手存一份        |
