# 0007 公网部署平台：Cloudflare Workers

- 状态：已定（2026-11-06）

## 背景

P0–P4 只能在局域网里使用：手机必须和运行开发服务器的电脑连在同一个 Wi-Fi 上。出门时无法使用。
约束条件：大陆和海外都要能用；尽量免费；服务端里有百炼的 key，上线前必须先加访问保护（另见决策 0008）。

## 决定

部署到 Cloudflare Workers。前端静态文件和 AI 代理放在同一个 Worker 里，一个网址同时提供两者。
先使用免费的 `*.workers.dev` 域名，在大陆网络下实测；如果打不开，再购买域名接入 Cloudflare。服务器不在大陆，所以不需要备案。

## 理由

- 免费额度（每天 10 万次请求）远超个人使用量。
- 服务端用的 Hono 框架原生支持 Workers，改动小。
- 自带 HTTPS，录音和系统分享都需要它，局域网测试时的自签名证书警告也会消失。

## 备选方案

| 方案                                        | 不选的原因                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------------------------- |
| Vercel / Netlify                            | 默认域名在大陆基本无法访问                                                             |
| 国内云函数（阿里云函数计算 / 腾讯云云函数） | 要稳定访问网页需要绑定自有域名，而大陆服务器必须备案（数周、需实名）；免费额度也在收紧 |
| 家里电脑 + 内网穿透                         | 电脑必须一直开机；免费穿透服务不稳定                                                   |

## 已知风险

- `*.workers.dev` 在大陆的可用性未经实测；兜底方案是购买自有域名，但大陆访问速度仍然一般。
- 免费版限制每次请求的 CPU 时间。代理大部分时间在等待百炼返回，等待时间不计入 CPU 时间，预计够用，部署后需要实测。
- 部署需要开发者本人注册 Cloudflare 账号，并在本机完成一次授权登录。
