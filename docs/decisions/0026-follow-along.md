## 1. 存在哪（原定 R2，改用 KV）

- 原计划在用户的 Cloudflare 账号里建 R2 存储桶（用户同意直接建），但账号还没开通 R2：要在控制台里开通，
  通常要先绑定付款方式，这只能用户自己做。
- 改用 Workers KV：不用付款方式，免费额度 1 GB 存储、单个值最大 25 MB、每天 1000 次写入，个人分享够用。
  已建好命名空间 `SHARES`。以后要换 R2，只改服务端的存取几行。

| 备选                  | 取舍                                                            |
| --------------------- | --------------------------------------------------------------- |
| **A Workers KV**      | **选定**。现在就能用；有自带的过期删除；单个值 25 MB 够一次出行 |
| B R2                  | 容量和写入次数更宽，但要用户先在控制台开通                      |
| C Durable Object 存储 | 也要付费套餐                                                    |

## 2. 怎么加密（推荐 A）

- 在手机上把这次出行打包成一个文件：标题、日期、路线、每条记录（标题、日期、地点、天气、正文、最多 3 张照片）。
  照片缩到长边 1280 像素，整个文件不超过 25 MB（照片最多 40 张）。
- 用随机生成的钥匙加密（AES-GCM 256 位，浏览器自带），上传的是加密后的字节。
- 钥匙只在链接 `#` 后面：`…/s/<编号>#k=<钥匙>`。浏览器不会把 `#` 后面发给服务器，所以服务器存的是它打不开的东西。
- 链接被转发出去，拿到的人也能看（和 Polarsteps 的"秘密链接"一样）；页面上写明这一点。

## 3. 分享时的隐私选项（第三节 2–6）

- **带哪些**：正文带不带、照片带不带。
- **位置精度**：精确 / 大概（坐标只留到约 5 公里）/ 不显示地图。
- **隐私区**（0022）：圈里的记录不带坐标，路线里圈内的点去掉。
- **有效期**：7 天 / 30 天 / 90 天，到期服务端自动删除；随时可以"撤回"（马上删除）。
- **不让搜索引擎收录**：看的页面和数据都带 `noindex`。
- **实时位置**：只分享记录，不分享轨迹的最新位置；路线只画到最后一条记录。

## 4. 更新（推荐 A）

- 出行中每记一条，App 打开时自动重新打包上传一次（需要联网和口令），朋友刷新就能看到新的一站。
- 也可以手动点"更新"。链接不变。
- 上传、更新、撤回都要"修改钥匙"：创建时服务端给的随机串，只存在你的手机里，服务端只存它的哈希。

## 5. 朋友看到的页面

- 不用装 App、不用账号：标题、日期和里程、路线示意图（0025）、按时间的每一站（照片、标题、日期、地点、天气、正文）。
- **一站一站翻**：全屏，点右边下一站、点左边上一站，显示第几站。
- **留言**（第二节 B+）：填昵称和一句话，用同一把钥匙加密后存上去；只有拿到链接的人能写、能看；每个链接最多 100 条。
  你在 App 里"看留言"。不做点赞。
- 页面单独一个入口（`share.html`），不加载 App 本身的代码。

## 6. 不做

- 账号、关注、推送（0002 的理由不变）。
- 实时位置。

## 实现（2026-11-24）

- 加密格式：`shared/shareFormat.ts`（App、看的页面、测试共用；只用 Web Crypto）。
- 服务端：`server/share.ts`，挂在 `/api/share`：新建（要口令）、更新和撤回（要修改钥匙）、取（公开、限流）、
  留言（公开、限流、每个链接 100 条）。KV 绑定 `SHARES`，本机用内存代替。`/s/*` 由 Worker 转给 `share.html`。
- App：`src/lib/follow.ts`（按选项打包、上传、更新、撤回、读留言、自动更新）、`FollowLinkCard.tsx`（在"回看"里）。
  数据库 v11：`shares` 表，进备份（换手机后还能更新、撤回）。
- 看的页面：`share.html` + `src/share/main.ts`，独立入口，不加载 App。

## 验证

- 单元测试 4 个：加密包往返、换钥匙解不开、密文里看不到原文、留言加解密；服务端存取更新撤回、没有修改钥匙改不了、
  撤回连留言一起删、有效期只能选 7/30/90、乱写的留言拒绝。
- 界面测试 3 个（Playwright，服务端是假的）：朋友的页面能解密、显示路线和每一站、一站一站翻（键盘左右）、
  留言发出去的是密文且能解开；过期和链接不完整有清楚的提示；App 里从"回看"生成链接，上传的是加密包。
- 没验证：线上 KV 的真实存取（部署后在 App 里点一次就知道）、手机上的效果、**大陆网络能不能打开链接**（要用户实测）。
