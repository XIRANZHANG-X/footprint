# 0003 场景范围与输入方式

- 状态：已定（2026-11-03 / 2026-11-04）

## 场景范围：旅行 + 本地探索

以"出门去了一个地方"为单位：旅行，加上探店、citywalk、看展、第一次去的地方。

- 理由：旅行一年只有两三次，频率太低；加入本地探索后，提高到每月几次。定位仍然清晰：记录去过的地方，而不是记录一切。
- 影响：地图要能放大到城市内部。
- 不选"只做旅行"：频率太低。不选"通用生活日记"：定位模糊，地图失去意义，竞争对手变成所有日记类 App。

## 输入方式：照片元数据 + 语音 + 文字

一次记录的操作：选几张照片 → 按住说一句话 → 完成。

- 照片：自动读取拍摄时间和 GPS。读不到 GPS 时，在地图上点一下，或由 AI 推测后请用户确认。
- 语音：一句话，用于提取感受；文字作为兜底。
- 不做后台轨迹：耗电、隐私敏感、必须是原生 App；照片的地点已经能串出去过哪些点。
- 不做视频：模型费用和处理时间都高。
- 已知问题：经过即时通讯工具传输的照片，元数据通常已被去除；手机网页的文件选择器也可能去掉 GPS。
