## 2. 一个计划里有什么

- 名字（比如"京都五日"）、出发日期、天数。
- 一串地方：第几天、名字、位置、备注（门票号、想吃的东西）；AI 排的还有一句推荐理由。
- 不做航班、住宿、订票邮件（`docs/polarsteps.md` 里说过：要收用户邮件，违反 0002）。
- 数据库 v10 新表 `plans`，进备份。

## 3. 到了提示（推荐 A）

- 计划的日期内（前后各放宽一天），某个地方 300 米内（城市、景区按边界）有了记录，就标"到了 ✓"。
- 正在记录路线时（0022），最近 3 小时的轨迹到了某个计划里的地方、还没有记录，时间线顶部提示"到了 X，记下这一站？"，
  点了打开"只写几句"，位置已填好。

## 4. AI 帮我排（推荐 A）

| 备选                                                           | 取舍                                                                            |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **A 文字模型按"你的口味"排每天去哪，App 再逐个用地名搜索核实** | **选定**。用的是 App 里已有的东西：常记的类别和标签、在那里去过的地方、想去清单 |
| B 只给模型目的地和天数                                         | 和随便问一个聊天机器人没区别                                                    |
| C 做成 Agent，让模型自己调工具搜地点、查天气                   | 更灵活，但调用次数多、慢、贵；放到后面"问问我的足迹"那批一起做                  |

- **发给模型的**：目的地、天数、你补充的一句话（"想多走路""带老人"）、你最常记的 8 个类别和标签、
  你在目的地已经去过的地方名（最多 30 个）、想去清单里在目的地的地方。不发照片、不发正文。
- **要求**：只推荐真实存在、地图上搜得到的地方，写正式名称；每天 2–4 个，顺路排；理由一句话、说明为什么适合你；
  去过的不再推荐；不编营业时间、价格、门票。
- **格式**：文字模型（qwen3.7-flash，关掉思考）的 JSON Schema 严格模式（0016）。
- **核实**：每个地方用"目的地 + 地名"搜一次（国内走高德），搜到就填上位置；搜不到标"没核实"，你可以删或者自己改。
- **和 0012"不编"的关系**：计划只是建议，不写进手账正文；推荐理由也只在计划里显示。

## 5. 倒计时（推荐 A）

- 首页统计下面一行：有还没开始的计划，显示"离「京都五日」出发还有 12 天"；正在进行中显示"「京都五日」第 2 天"；
  都没有，显示"上次出门是 23 天前"（最近一次出行的最后一天）。
- 安卓桌面小组件要写原生代码，先不做。

## 实现（2026-11-24）

- 服务端：`POST /api/plan`（`server/app.ts`），提示词 `PLAN_SYSTEM`、`planUserText`（`server/prompts.ts`），
  格式 `planContract` / `planResponse`（`shared/ai.ts`）。回复里没有 JSON 或格式不对返回 502。
- 前端：`src/lib/plans.ts`（到没到、到了提示、倒计时、口味）、`PlanPanel.tsx`（地图页"计划"）、地图上的
  `PlanLayer`（天空蓝的"D1、D2"小方块和虚线）、`StaySuggestions.tsx` 里加了"到了计划里的 X"、时间线顶部的倒计时。
- 数据库 v10：`plans` 表，进备份。AI 调用记进用量（类型 `plan`）。

## 验证

- 单元测试：服务端 4 个（严格格式、只发文字、坏请求不调模型、回复不对返回 502）；前端 5 个（到没到只看计划期间、
  到了提示、倒计时三种情况、口味）。
- 浏览器里：在地图页新建"杭州 3 日"（自己排），按天显示；地图上出现 D1、D2；轨迹到了断桥，时间线顶部提示
  "到了计划里的「断桥」"；倒计时显示"第 1 天"。
- **真实调用一次**（用户同意，每批不超过 1 元）：杭州 2 天、想多走路，口味 美食/面/咖啡/风景/寺庙，去过断桥和雷峰塔，
  想去灵隐寺。3.1 秒，261 / 200 token（qwen3.7-flash，约 0.0002 元）。
  - 结果：第 1 天灵隐寺（想去清单）、法喜寺；第 2 天南山路、知味观·味庄。没推荐去过的地方，理由都扣着口味。
  - 4 个都核实到了。**局限**：有分店的地方，搜索第一个结果可能是别的分店（知味观味庄搜到了钱江世纪城店），
    位置可能不对，要自己看一眼。以后可以按目的地的城市中心挑最近的结果。
