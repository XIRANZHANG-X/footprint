# 0002 分享：只生成分享链接，不做账号和好友

- 状态：已定（2026-11-03）

## 决定

分享图在设备本地生成；分享链接只包含文字摘要和低清缩略图，由用户自己发到即时通讯工具里。**没有账号体系，服务端不存任何用户数据**，只是一个转发 AI 请求的无状态代理。

## 备选方案

| 方案                                                  | 不选的原因                                                                                |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 自建完整社交（账号、好友、动态、评论）                | 冷启动难（朋友得先装 App）；公开运营涉及内容审核等合规要求；工程量大                      |
| 微信小程序                                            | 个人主体在社交和 UGC 类目上有限制；本地存储空间小，放不下照片；不适合开源后由他人自行部署 |
| 本地优先 + 私密圈子同步（朋友不用安装即可在网页查看） | 需要账号和同步服务器，现阶段工程量过大                                                    |

## 以后

如需圈子功能，给记录加一个"可见范围"字段即可，不需要推倒重来。
