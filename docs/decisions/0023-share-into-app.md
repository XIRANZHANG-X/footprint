# 0023 从相册"分享"进 App

- 状态：已定并实现（2026-11-24）。来源：`docs/polarsteps.md` 第五节第 12 条、待办第五档"从相册直接发给 App"。
  用户说"全部开始做"，按推荐做。

## 做法（推荐 A）

| 备选                                                         | 取舍                                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **A 在安卓里注册"分享"入口，自己写一个小插件把照片交给网页** | **选定**。在相册里选几张 → 分享 → 记进足迹手账，直接进新建流程；不加依赖 |
| B 社区插件（`@capgo/capacitor-share-target` 之类）           | 省一点代码；多一个依赖，要核对它怎么处理照片里的位置信息                 |
| C 不做，继续在 App 里"选照片"                                | 每次要先开 App 再翻相册，正是"懒得整理"的门槛                            |

- 分享菜单里显示"记进足迹手账"，一张、多张都行。
- 原生那边（`ShareInPlugin.java`）把照片**原样复制**到 App 的缓存目录，不重新编码，拍摄时间和位置都保留；
  网页（`src/lib/shareIn.ts`）读成文件，交给和"选照片"一样的流程。
- App 没开着时分享进来，打开后自动接上；开着时立刻接上。正在写别的记录时不打断，提示"先写完手上这条"。
- **照片里的位置**：安卓 10 起，从相册分享来的照片默认去掉位置。第一次分享时 App 会申请"读取照片中的位置"
  （`ACCESS_MEDIA_LOCATION`），同意了才拿得到原图里的位置；不同意也照样导入，没有位置的照片按拍摄时间到轨迹里补（0022）。

## 没验证

- 只能在真机上测：分享菜单里有没有出现、一张和多张、App 开着和没开着、照片位置在不在。这些要你装上新版测。
- 安卓正式版能编译。
