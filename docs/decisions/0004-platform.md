# 0004 平台：网页 + 安卓，暂不做 iOS 打包

- 状态：已定（2026-11-05）

## 决定

一套 React 代码。网页版优先；安卓用 Capacitor 打包成 App；iOS 用户先使用网页版。

## 理由

- 一套代码可以同时运行在网页和原生外壳里，后续要做 iOS 时也不需要改代码。
- 原生外壳的数据存在 App 自己的存储中，不会被浏览器清理；通过原生相册接口读取 GPS 也更可靠。
- 开发机是 Windows，安卓可以免费打包。iOS 打包需要 macOS，分发给他人还需要加入苹果开发者计划（99 美元/年）。在确实有 iOS 用户需要之前，不付这个成本。

## 网页版的存储风险与缓解

IndexedDB 中的数据可能丢失：Safari 会清理长时间未访问的网站数据，用户可能清除浏览器数据，换设备或换浏览器不会带走数据，存储也有配额限制。
缓解措施：提示用户把网页加到主屏幕；调用 `navigator.storage.persist()` 申请持久化存储；定期提醒导出备份。

## 备选方案

| 方案                   | 不选的原因                             |
| ---------------------- | -------------------------------------- |
| 纯网页（PWA）          | 存储可能被清理，照片的 GPS 也可能丢失  |
| Flutter / React Native | 要学新语言，或者分享查看页还要另写一套 |
| 微信小程序             | 见 0002                                |
