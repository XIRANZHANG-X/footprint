# 0010 视觉风格：像素风 + 马卡龙配色

- 状态：已定（2026-11-09）

## 背景

P0–P5 的界面一直用 Tailwind 默认的样子：灰底、白卡片、绿色主按钮。功能都跑通了，但用户觉得"太丑"，
而且和别的 App 分不出来。用户说不清自己喜欢的风格，看了六张风格样张后，
拿出了一个参考：RetroUI（retroui.io，一个像素风 React 组件库）的首页截图，
要求"类似这种像素风，但用马卡龙配色"。

## 决定

只借参考的风格要素，不用它的代码，也不引入这个组件库。

- 底纸：奶油白，带很浅的方格。
- 卡片和按钮：2 像素深色描边，直角，往右下错开的实心硬阴影（不模糊）；按钮按下时阴影收回、按钮下沉。
- 配色：五种马卡龙色，每种颜色只表示一类东西——
  草莓粉 = 主要操作，薄荷绿 = AI 和完成，香芋紫 = 出行分组，柠檬黄 = 提醒和待定位，天空蓝 = 地图和地点。
  描边和文字统一用深紫黑色，不用纯黑。
- 装饰（像素星星、斜放的卡片）只用在空状态和分享图上，记录列表里不放。

### 中文像素字体

用"缝合像素字体"（Fusion Pixel Font，TakWolf，OFL 字体协议）的 12 像素、简体版本。

- 只用在标题、按钮、标签上；正文（AI 写的介绍、用户原话）继续用系统字体。
- 字体文件裁剪到常用字（约 3500 字），页面先用系统字体显示，像素字加载好以后再换上（`font-display: swap`）。
- 不在常用字里的字（多见于地名）会用系统字体显示，同一个标题里会混着两种字，接受这个代价。
- 实际裁剪结果（2026-11-09，fontTools）：GB2312 一级字库 3755 字 + ASCII + 中英文标点和全角符号 + `src/` 里出现过的所有字，
  共 4057 个字形，文件从 701 KB 降到 109 KB。界面里只有 ✂ 和一个 emoji 不在字体里，由系统字体显示。
  以后界面加了新字，要重新跑一次 `scripts/subset_font.py`（需要 `pip install fonttools brotli`；输入是字体发布包里的
  `fusion-pixel-12px-proportional-zh_hans.otf.woff2`，版本 2026.10.25）。
- 分享图也用像素字画标题和标签；画之前先等字体加载完，加载失败就退回系统字体，照样出图。

| 字体方案               | 不选的原因                                          |
| ---------------------- | --------------------------------------------------- |
| 完整字体不裁剪         | 文件大好几倍，网页版第一次打开明显变慢              |
| 正文也用像素字         | AI 正文常有好几行，像素字读长段很累，小字号还容易糊 |
| 只有英文和数字用像素字 | 界面基本是中文，像素感会弱很多，不像用户选的风格    |
| 10 像素版本            | 中文笔画挤，看久了累                                |
| Zpix（最像素）         | 商用要另外授权，不适合以后开源                      |

## 备选方案（风格）

用户看过的六张样张：纸质手账、极简留白、杂志大图、柔和圆润、夜色胶片、复古印刷。
最后选的方向是"像素风 + 马卡龙色"，不在这六种里，是用户自己的参考。
