# 0005 技术栈默认值

- 状态：默认值，P1 之后可调整（2026-11-05）

| 项目       | 选择                                                                                              | 理由                                                           | 不选的方案                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 前端       | Vite + React + TypeScript（strict）+ Tailwind 4                                                   | 纯客户端应用，Capacitor 需要静态产物                           | Next.js：用不到服务端渲染，静态导出要额外配置                                        |
| 服务端     | Node + Hono 无状态代理（`server/`）                                                               | 和前端同一种语言，可以共用 Zod 数据结构                        | FastAPI：要维护两种语言，类型无法共享                                                |
| 本地数据   | Dexie（IndexedDB）；照片存压缩版（长边约 2048px）和缩略图                                         | 原图会撑爆存储配额                                             | 存原图                                                                               |
| 照片元数据 | exifr                                                                                             | 成熟、体积小                                                   | 自己解析                                                                             |
| AI         | 阿里云百炼（OpenAI 兼容接口）：先做语音识别（结果可修改），再用视觉模型生成结构化记录（Zod 校验） | 转写结果可以单独确认；结构化输出方便检索，也方便以后做偏好学习 | 一次全模态调用：转写结果无法单独修改                                                 |
| 地名       | 由代理调用 Nominatim（OSM），限速每秒 1 次                                                        | 免费，不需要 key                                               | 高德：国内地点更准，但需要 key，还要处理 WGS-84 与 GCJ-02 的坐标转换，留作以后的选项 |
| 地图       | Leaflet + OSM 瓦片，瓦片源可配置                                                                  | 需要能放大到城市内部                                           | D3 世界地图：只能到国家和省份                                                        |
| 出行归组   | 规则法（时间间隔或距离超过阈值）                                                                  | 简单、可解释                                                   | 让 AI 归组：贵，结果也不稳定                                                         |
| 测试       | Vitest                                                                                            | 与 Vite 集成好                                                 | —                                                                                    |
| 代码检查   | oxlint（Vite 模板自带）+ Prettier                                                                 | 模板默认，速度快                                               | ESLint：原计划用它，但模板已改用 oxlint，没必要替换                                  |
| 开源协议   | 默认 MIT，公开前再确认                                                                            | —                                                              | —                                                                                    |
